My current work spans robotics, embedded systems, machine learning, and applied research, with a growing focus on research-driven engineering and international graduate opportunities.

- 🤖 **Robotics:** Embedded systems, gesture-controlled interfaces, and robotic simulation.
- 🧠 **Machine Learning:** Classification, data analysis, and practical ML applications.
- 🔬 **Research:** PCA, heavy-metal analysis, and ML-assisted environmental research.
- ⚡ **Engineering:** Python applications, hardware integration, and real-time systems.
- 🎓 **Long-term goal:** Pursue a fully funded master's degree abroad and contribute to impactful research.

- Developing an **8-channel EMG gesture-recognition system** using ESP32-S3, BNO080, and Random Forest classification.
- Building a **Tuya-based smart energy monitoring and sub-metering system** with room-level energy tracking and carbon estimation.
- Exploring **robotic arm simulation** using Python and PyBullet.
- Contributing to robotics development through the **EWU Robotics Club**, including RAPTOR-related software and low-cost prototyping.
- Working on environmental heavy-metal analysis and exploring **PCA and machine learning** for coastal Bangladesh datasets.
- Strengthening my research portfolio, technical foundations, and profile for fully funded international master's opportunities.
